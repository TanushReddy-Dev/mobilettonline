# 🏓 WTT Arena Pro — Pocket Table Tennis Online

> ### 🎮 **Play Live Now**: [https://tanushreddy-dev.github.io/mobilettonline/](https://tanushreddy-dev.github.io/mobilettonline/)

A high-performance 3D table tennis web game with real-time P2P online multiplayer via WebRTC (PeerJS). Irrespective of where you or your friends are, open the link, generate a 4-character code or share an invite link, and play in real time!

## 🌐 Live Online Multiplayer Features
- **Online Play with Match Codes**: Create a room, share your 4-character code or direct link with a friend, and play anywhere in the world.
- **Low-Latency P2P WebRTC**: Direct browser-to-browser DataChannel communication with client-side dead-reckoning and instant hit feedback.
- **Symmetrical 3D Perspective**: Both players play naturally from behind their paddle at the bottom baseline.
- **Full Physics Engine**: Realistic ball spin, topspin, backspin, sidespin (Magnus effect), edge bounces, net cords, smashes, and drop shots.
- **Zero Server Setup**: Fully client-side single-page app (`index.html`).

## 🚀 How to Enable GitHub Pages (Free 24/7 Hosting)

1. Push this repository to GitHub.
2. In your GitHub repository, go to **Settings** > **Pages** (in the left sidebar).
3. Under **Build and deployment** > **Branch**:
   - Select `main` (or `master`) branch.
   - Select `/ (root)` folder.
   - Click **Save**.
4. In about 30 seconds, your game will be live at:
   `https://<your-github-username>.github.io/<repository-name>/`
5. Share the URL with anyone and play together with match codes!
