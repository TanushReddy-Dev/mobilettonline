# Courtlight Broadcast — visual concept

Static direction board for the Pocket Table Tennis visual overhaul.

- Open `concept/courtlight.html` in a browser.
- Board preview: `concept/preview/board.png`
- Individual screens: `concept/preview/start-arena.png`, `start-daylight.png`, `game-arena.png`, `game-daylight.png`, `settings-arena.png`, `settings-daylight.png`, `compact-320.png`
- Component language: `concept/preview/components.png`

## What to review

1. Start screen: hero court, bottom sheet, Play Solo hierarchy.
2. Broadcast strip: score, serve, telemetry, adaptive 320 px state.
3. Court art: table, paddles, ball, studio lighting.
4. Settings: four groups and the System / Light / Dark control.
5. Component language: typography, palette, buttons, controls, icons.
6. Primary action options: **A · Studio white** (recommended) or **B · Cyan fill**.

This folder is a concept only. `index.html` and gameplay remain untouched.
